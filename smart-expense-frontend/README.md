# SmartExpenseAnalyzer frontend

The frontend is a React/Vite dashboard for authenticated profiles, budgets, expenses, and asynchronously generated financial insights. The complete architecture, Docker Compose setup, API contracts, and CI workflow are documented in the [root README](../README.md).

Run frontend checks from this directory:

```bash
npm ci
npm test
npm run lint
npm run build
```

Use `npm run dev` for local Vite development when the backend stack is available.
